# Family Budget Agent (Graduation Project 2)

The `gp2-agent` branch holds the work of Graduation Project 2: a ReAct tool-calling agent for household budgets.

`baseline/` is Graduation Project 1 ("ميزان"), unchanged. Run it from inside that folder with the root environment:

```
cd baseline
..\venv\Scripts\python -m streamlit run app.py
```

The architecture is specified in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
